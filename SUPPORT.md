# Support

## Where to get help

- **Bug reports:** Open a [GitHub Issue](issues) with clear reproduction steps. Use the bug report template.
- **Feature requests:** Open a [GitHub Issue](issues) using the feature request template.
- **Questions & discussions:** If GitHub Discussions is enabled for this repository, use it for general questions and ideas. Otherwise, open an issue and label it appropriately.

## Guidelines

- Please search existing issues/discussions before opening a new one.
- For security issues, follow the process in [SECURITY.md](SECURITY.md) (do not report publicly).
- Response times are not guaranteed; maintainers will help as capacity allows.
- When asking for help, include relevant details (OS, Node version, environment, logs) to reproduce issues.
