# `@proudlyopensource/typescript-config`

Shared `tsconfig.json` files for the Proudly Open Source monorepo.

- `base.json` – strict baseline for every package.
- `nextjs.json` – for Next.js applications.
- `react-library.json` – for React component packages.

## Usage

```json
{
  "extends": "@proudlyopensource/typescript-config/nextjs.json"
}
```
